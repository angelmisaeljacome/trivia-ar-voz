Proceso de instalación:
1. Instalar libreria de flask -> pip install Flask
2. Descargar repositorio del juego -> https://github.com/angelmisaeljacome/trivia-ar-voz
3. Ejecutar con python app.py
4. Abrir el juego en localhost:5000
5. Usar la cámara y marcadores impresos para jugar. Escenografia opcional.
